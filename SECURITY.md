# Security Policy

Report a vulnerability via [GitHub private vulnerability reporting](https://github.com/bgauduch/dotfiles/security/advisories/new)
(Security → Advisories → Report a vulnerability). Please don't open a public issue for
suspected vulnerabilities.

Include: affected file/commit, reproduction steps, and impact. Expect an initial
response within 7 days.

Supply-chain posture (pinned versions, checksum verification, secret scanning) is
traced in [`docs/adr/0003-dependencies-trust-supply-chain.md`](docs/adr/0003-dependencies-trust-supply-chain.md)
and [`docs/THREAT-MODEL.md`](docs/THREAT-MODEL.md).
